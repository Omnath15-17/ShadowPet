

# 🐉 Cursor Creature

A desktop pet made with Python and Pygame that follows your mouse cursor.

## Features

* 🐉 Dragon
* 🐍 Serpent
* 🕷️ Spider
* 🐛 Centipede
* 🎨 Multiple colour themes
* 🖥️ Desktop Only mode
* 📌 Always On Top mode
* ⌨️ Keyboard shortcuts

## Requirements

* Windows
* Python 3
* Pygame

## Run from Source

```bash
pip install -r requirements.txt
python cursor_creature.py
```

## Controls

* `Ctrl + Shift + Q` → Quit
* `Ctrl + Shift + M` → Return to menu

## Build EXE

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole cursor_creature.py
```

The executable will be created inside the `dist` folder.

## About
